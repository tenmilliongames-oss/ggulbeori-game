## 요약

- 전체 길이는 약 119.8초, 해상도는 1336x748, 30fps다.
- 구조는 `인트로 -> 문제 카드 -> 정적 퍼즐 표시 + 카운트다운 -> 시간 종료 컷 -> 정답 공개 -> 다음 스텝 예고`다.
- 핵심 본편은 실시간 상호작용이 아니라, 미리 준비된 좌우 이미지와 HUD를 일정 시간 유지한 뒤 정답 마커를 순차적으로 덧그리는 선형 타임라인이다.
- 퍼즐 구간에서 카메라 이동이나 장면 레이아웃 변화는 거의 없고, 시간 숫자와 상단 문구만 바뀐다.

## 움직임/타이밍 관찰

- 퍼즐 본편은 사실상 정지 화면이다. 의미 있는 변화는 `상단 문구`, `카운트다운 숫자`, `정답 마커 등장`뿐이다.
- 정답 마커는 한 번에 전부 나오지 않고 짧은 간격으로 순차 공개된다.
- 줌, 패닝, 패럴랙스 같은 카메라 연출은 확인되지 않았다.
- 따라서 문제 장면의 핵심 단위는 `배경 이미지 2장 + HUD + 이벤트 타임라인`이다.

## 제작 도구 관점 결론

- 이 레퍼런스는 게임 플레이 시스템보다 `문제 저작기 + 컷 기반 시퀀서 + 2D 영상 렌더러`에 가깝다.
- 저작 단계에서 사람이 정답 위치를 직접 찍고, 실행 단계에서는 그 좌표를 정해진 시점에 오버레이하면 레퍼런스 연출을 거의 그대로 재현할 수 있다.
- 우선순위는 `프로젝트 파일`, `문제 편집기`, `정답 좌표 저장`, `장면별 지속시간`, `영상 내보내기`이며 입력 판정/실시간 상태머신은 불필요하다.
