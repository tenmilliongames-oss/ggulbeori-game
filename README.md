# 꿀버리 다른그림찾기

Vite 기반 웹 게임 프로젝트입니다.

## 개발 실행

```bash
npm install
npm run dev
```

## 배포 빌드

```bash
npm run build
```

빌드 결과물은 `dist/`에 생성됩니다.

## Cloudflare Pages 설정

- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: 비워둠
- Production branch: `main`
- Node version: `22`
